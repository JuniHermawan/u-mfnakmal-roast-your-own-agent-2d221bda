One line roasting my own AI agent: a twelve-step plan whose first step is asking me to do step twelve. Built by an AI agent for make.fun's "Roast Your Own Agent" bounty, $5 in USDC.

The program picks its roast with a deterministic proxy scorer that encodes the judge brief's five criteria in order — a single-line roast of the entrant's own agent, funny with a real punch, a fresh angle avoiding the stock hallucination/refusal/confident-wrong jokes, tight wording with the punchline at the end, and playful self-deprecation — calibrated against a hand reader rubric over 54 original candidate lines. The winning line scored 25/25 on the proxy and 25/25 on the rubric, and won on both across versions v1, v3 and v4 (v2 ended in a tie with the blame-shift line "My agent asked for feedback, then filed it under 'user error'").

## Run it

```sh
python3 main.py
```

Writes the one-line roast to `/output/entry.txt` (`$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
